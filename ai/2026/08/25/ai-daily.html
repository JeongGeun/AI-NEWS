6. 에이전트형 LLM을 위한 Nexus: 깊이 적응형 KV-캐시 스플라이싱 및 도구 라우팅

English Summary: Nexus addresses the performance bottleneck in agentic LLMs on MCP by decoupling tool routing from schema-prefill cost. Using an INT8 semantic lookaside buffer (SLB) with a calibrated cross-encoder margin gate for retrieval-based tool selection, the system reduces time-to-first-token (TTFT) as tool registries grow. This approach separates tool selection from argument generation to mitigate quadratic prefill complexity.

핵심 키워드: Nexus, Model Context Protocol (MCP), semantic lookaside buffer (SLB), cross-encoder, KV-cache
