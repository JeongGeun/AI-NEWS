5. Claude Code 워크플로우용 오픈소스 검증 도구 공개

출처: Dev.to · 중요도: 보통

한국어 요약: 개발팀이 파일 기반 에이전트 워크플로우에서 ‘완료’ 요청이 실제 결과물 없이 승인되는 문제를 해결하기 위해 ‘ack-is-not-done-guard’ 검증 도구를 오픈소스로 공개했다. 이 도구는 acknowledged, working, artifact_delivered, proven_done 4가지 상태를 정의하고, 실제 결과물과 검증된 증거가 존재할 때만 완료를 인정한다. 의존성이 없는 경량 도구로 기존 에이전트 운영 시스템에 쉽게 통합될 수 있다.

English Summary: A team open-sourced ack-is-not-done-guard, a lightweight validator for Claude Code’s file-based workflows that prevents false “done” claims without proper artifacts or proof. The tool enforces four distinct states and only allows completion when artifacts exist and checks have passed with evidence. It’s designed as a modular completion-checking layer that integrates with existing agent-ops systems.

핵심 키워드: ack-is-not-done-guard, Claude Code, Dev.to, file-based workflows
