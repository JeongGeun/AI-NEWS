1. TypeSafe AI, 새로운 LLM 형태 ‘System One’ 공개

출처: Simon Willison’s Blog · 중요도: 높음

English Summary: TypeSafe AI introduced Jev, a new category of language model called ‘System One’ or ‘decision models,’ which accepts text input but returns probabilistic decisions (yes/no answers, ratings, confidence scores) as floating-point numbers instead of text. The model is significantly cheaper than traditional LLMs, charging only $0.042 per million input tokens with free output, making it particularly cost-effective for classification and decision-making tasks.

4. Langflow OSS 인증된 RCE 취약점 (CVE-2026-17633)

출처: Dev.to · 중요도: 높음

한국어 요약: 오픈소스 LLM 애플리케이션 빌더 Langflow의 /api/v1/custom_component 엔드포인트에서 인증된 사용자가 원격 코드 실행(RCE)을 수행할 수 있는 취약점이 발견되었다. CVE-2026-17633으로 등록된 이 취약점은 CVSS 8.5의 높은 심각도를 가지며, 버전 1.0.0~1.10.3에 영향을 준다. 커스텀 컴포넌트 기능에서 코드 검증 프로세스가 부재해 발생한 것으로 분석된다.

English Summary: A high-severity authenticated Remote Code Execution (RCE) vulnerability (CVE-2026-17633, CVSS 8.5) was disclosed in Langflow OSS versions 1.0.0–1.10.3 via the /api/v1/custom_component endpoint. The vulnerability stems from improper code validation in the Custom Components feature, allowing authenticated users to execute arbitrary Python code when LANGFLOW_ALLOW_CUSTOM_COMPONENTS is enabled.
