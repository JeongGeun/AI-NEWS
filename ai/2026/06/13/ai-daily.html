2. LLM의 도구 지식 감사 프레임워크 ToolSense

출처: arXiv cs.AI · 중요도: 높음

한국어 요약: 대규모 언어모델(LLM)이 수많은 도구 카탈로그를 활용할 때 도구 검색 병목 현상을 해결하기 위한 새로운 진단 프레임워크 ToolSense를 제안한다. 이는 매개변수 기반 도구 검색 방식으로 각 도구를 가상 토큰으로 인코딩하고 두 단계 미세조정(암기 및 검색)을 통해 LLM을 검색기로 활용하여 높은 성능을 달성한다.

English Summary: ToolSense is a diagnostic framework that addresses the tool-retrieval bottleneck in LLMs deployed over large tool catalogs. Using parametric tool retrieval, it encodes each tool as a virtual token in the LLM vocabulary and fine-tunes it in two stages (memorization then retrieval SFT) to leverage the LLM itself as an effective retriever, achieving strong performance compared to embedding-based approaches.

핵심 키워드: ToolSense, LLM, parametric tool retrieval, virtual tokens, semantic embeddings
