출처: GeekNews · 중요도: 높음

한국어 요약: Anthropic과 Theorem의 협력으로 Claude LLM이 대규모 소프트웨어 정형 검증을 수행할 수 있음을 입증했다. RISC-V 어셈블리 코드 수준에서 100개 이상의 오픈소스 라이브러리의 보안 속성을 증명했으며, 수년간 발견되지 않은 버그도 발견했다. 이는 AI를 프로덕션 소프트웨어에 적용한 첫 대규모 정형 검증 사례로, 향후 안전한 소프트웨어 개발의 필수 요소가 될 것으로 예상된다.

English Summary: LLMs can now produce formal proofs at scale, enabling security verification of production software. Using Claude, researchers proved security properties in over 100 real-world open-source libraries at the assembly code level and discovered previously undetected bugs, marking the first large-scale AI-driven formal verification effort in production software.

핵심 키워드: Anthropic, Theorem, Claude, RISC-V, formal verification
