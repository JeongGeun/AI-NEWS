2. Claude Sonnet 5 출시: Opus 4.8 수준 성능, 저렴한 가격

출처: Simon Willison’s Blog · 중요도: 높음

한국어 요약: Anthropic이 Claude Sonnet 5를 출시했다. 성능은 Opus 4.8에 가깝지만 더 저렴한 가격으로 제공된다. 새로운 토크나이저로 인해 같은 입력 텍스트가 약 30% 더 많은 토큰을 생성되어 실제 가격 인상 효과가 있다. API 변경 사항으로는 temperature, top_p, top_k 파라미터 제거, 100만 토큰 컨텍스트 윈도우, 적응형 사고(Adaptive thinking) 기본 활성화 등이 있다.

English Summary: Claude Sonnet 5 has been released with performance close to Opus 4.8 at lower pricing ($3/$15 per million tokens). However, a new tokenizer generates approximately 30% more tokens for the same input text, effectively offsetting the price reduction. Key API changes include removal of sampling parameters, 1M token context window, and adaptive thinking enabled by default.

핵심 키워드: Anthropic, Claude Sonnet 5, Claude Opus 4.8, Simon Willison
