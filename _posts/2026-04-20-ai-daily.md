This enables researchers to use standard git commands like log, diff, and blame to trace prompt evolution and compare changes across Claude versions without manual parsing.

**한국어 요약**: 개발자가 자신의 파이썬 코드베이스 124개 파일을 Claude Opus 4.7 LLM으로 보안 감사했으며, 총 비용은 0.90달러였다. 감사 결과 심각한 취약점 0건, 높음 1건, 중간 2건이 발견되었으며, 그 중 1건은 실제 버그로 즉시 수정되었다. 이는 LLM을 활용한 경제적이고 효율적인 보안 감사 방법을 보여주는 사례이다.

**English Summary**: A developer conducted a security audit of their Python codebase using Claude Opus 4.7 LLM with prompt caching for just $0.90, scanning 124 files in 22 seconds. The audit found 1 critical bug (related to subprocess stdout/stderr handling in a SQLite ledger) and 2 legitimate security risks, demonstrating cost-effective LLM-powered security analysis.
