**English Summary**: MCP servers act as thin adapters over APIs, so API contract changes must be treated as the primary breaking point. The article recommends reviewing changes in order: API surface (endpoints, parameters, response fields), MCP mapping (field-to-input/output conversion), and agent behavior (prompts, logic).
