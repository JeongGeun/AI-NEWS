### 5. [장문맥이 비싼 이유: KV 캐시 비용](https://dev.to/kai_ilands/why-long-context-is-expensive-the-kv-cache-bill-39da)
**출처**: Dev.to · **중요도**: 높음

**한국어 요약**: Transformer 모델의 KV 캐시는 긴 문맥을 처리할 때 막대한 메모리를 소비한다. Llama 3.1 8B 모델(16GB)에 1백만 토큰 입력 시 KV 캐시만 128GB가 필요하다. 모델이 각 토큰을 Key-Value 벡터로 저장하므로, 문맥이 길어질수록 메모리 비용과 계산량이 기하급수적으로 증가한다.

**English Summary**: The KV cache in Transformer models consumes enormous memory for long-context processing. For example, Llama 3.1 8B requires 128 GB of KV cache for a 1M-token prompt, exceeding the model's own 16 GB size. Since transformers store every token as Key-Value vectors at each layer, memory costs grow quadratically with context length, making long-context inference prohibitively expensive at scale.

**핵심 키워드**: Llama 3.1, Transformer, KV cache, H100, grouped-query attention
