**한국어 요약**: Vercel Labs가 개발한 UI SDK는 AI 에이전트가 UI의 기본 동작(키보드 네비게이션, 포커스, 선택, 드래그 드롭 등)을 조합하여 컴포넌트를 자동으로 구축할 수 있는 라이브러리입니다. React, Vue, Svelte, Solid, Web Components 등 주요 프레임워크를 지원하며, 현재 베타 단계입니다. 개발자가 복잡한 UI 로직을 직접 작성할 필요 없이 AI 에이전트가 이를 처리하도록 설계되었습니다.

**English Summary**: Vercel Labs launched UI SDK, a library that enables AI agents to construct UI components by combining basic behaviors like keyboard navigation, focus management, drag-and-drop, and ARIA attributes. The SDK supports multiple frameworks (React, Vue, Svelte, Solid, Web Components) and is currently in beta, allowing developers to leverage AI agents for component generation without writing complex UI logic manually.

**핵심 키워드**: Vercel Labs, UI SDK, @ui-sdk/core, React, Vue, Svelte
