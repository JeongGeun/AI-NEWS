**한국어 요약**: key-amnesia는 AI 에이전트가 암호와 API 키를 사용하면서도 이를 직접 접근하지 못하도록 하는 보안 도구입니다. 기존 .env 파일의 보안 위협을 해결하기 위해 암호화된 볼트에 시크릿을 저장하고, 에이전트가 필요한 명령 실행 시에만 환경변수로 값을 주입합니다. 마스터 비밀번호는 사용자만 물리 키보드로 입력 가능하며, 에이전트의 접근으로부터 완전히 차단됩니다.

**English Summary**: key-amnesia is a security tool that allows AI agents to execute commands using passwords and API keys without exposing them to the agent itself. It stores secrets in an encrypted vault and injects values into child processes during command execution, preventing agents from reading or leaking sensitive data. The tool also censors secrets from command output and restricts the master password to human-only input via physical keyboard.

**핵심 키워드**: key-amnesia, AI agents, .env security, encrypted vault, secret management
