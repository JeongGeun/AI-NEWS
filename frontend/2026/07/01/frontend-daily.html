3. CSS 의사클래스와 JavaScript 이벤트의 경계 변화

출처: CSS-Tricks · 중요도: 보통

한국어 요약: CSS는 JavaScript 이벤트 처리 대신 의사클래스를 활용하여 상태 변화에 대응하는 추세가 증가하고 있다. :hover, :active, :focus 등의 의사클래스들이 이벤트 리스너처럼 작동하며, 향후 Animation Triggers 스펙의 event-trigger 제안이 CSS에서 직접 이벤트를 감지하고 애니메이션을 트리거할 수 있게 할 것으로 예상된다. 이는 CSS의 역할과 기능이 점차 확대되고 있음을 보여준다.

English Summary: CSS is increasingly using pseudo-classes like :hover, :active, and :focus to handle what were traditionally JavaScript event responsibilities, blurring the line between CSS states and JavaScript events. The upcoming event-trigger proposal in the Animation Triggers spec would allow CSS to directly listen for events and trigger animations, further expanding CSS’s capabilities beyond traditional state management.

핵심 키워드: CSS-Tricks, Animation Triggers spec, event-trigger, pointer events

3. VS Code에서 동영상 음성 재생 문제 해결 방법

출처: Dev.to JavaScript · 중요도: 보통

한국어 요약: VS Code에서 MP4 동영상 재생 시 음성이 나오지 않는 문제는 Chromium 기반의 Electron이 AAC 오디오 코덱을 지원하지 않기 때문입니다. 이를 해결하기 위해 WebAssembly로 컴파일된 FFmpeg을 확장 프로그램에 번들링하여 오디오 트랙을 MP3로 변환한 후 재생하는 방식의 Modern Video Player 확장 프로그램이 개발되었습니다.

English Summary: VS Code video playback lacks audio because Electron’s Chromium build doesn’t include the AAC decoder due to patent licensing. A developer created the Modern Video Player extension that bundles FFmpeg as WebAssembly (~9 MB) to extract and transcode audio tracks to MP3, allowing seamless video playback with sound directly in the editor without external dependencies.

핵심 키워드: VS Code, Electron, Chromium, FFmpeg, WebAssembly, Modern Video Player, AAC decoder, MP3

4. 실시간 차트의 성능을 좌우하는 데이터 구조와 메모리 할당의 함정

출처: Dev.to JavaScript · 중요도: 보통

한국어 요약: React 앱에서 고속 원격 측정 데이터를 처리할 때 고정 크기 순환 버퍼(circular buffer)를 사용하면 메모리 할당 효율성을 극대화할 수 있습니다. 일반적인 배열 사용 시 push/shift 연산의 성능 저하 문제가 발생하지만, 순환 버퍼와 적절한 읽기 방식의 조합으로 이를 해결할 수 있습니다. 저자는 실제 구현 과정에서 발견한 메모리 할당의 함정과 해결 방법을 공유합니다.

English Summary: When handling high-frequency telemetry data in React applications, a fixed-size circular buffer is more efficient than a plain array for storing chart data. The key issue is memory allocation rather than access speed; using shift() on arrays causes O(n) performance degradation. The optimal solution combines the circular buffer structure with careful read operations to eliminate unnecessary allocations.

핵심 키워드: React, circular buffer, telemetry data, memory allocation, JavaScript
