5. URL 프래그먼트를 활용한 진정한 영지식 파일 공유 기술

출처: Dev.to JavaScript · 중요도: 높음

한국어 요약: HTTP URL의 ‘#’ 이후 프래그먼트는 서버에 전송되지 않는 클라이언트 전용 속성이다. 이를 AES-256 암호화 키 저장소로 활용하면 서버가 침해당해도 복호화 불가능한 영지식 파일 공유가 가능하다. 1996년부터 존재한 HTTP 표준 기능을 보안 용도로 재활용하는 혁신적 접근법이다.

English Summary: URL fragments (the part after #) never reach the server due to HTTP protocol specifications, making them ideal for storing AES-256 encryption keys client-side only. This enables true zero-knowledge file sharing where even a compromised server cannot decrypt files. The technique leverages a 1996 HTTP standard feature that has been largely overlooked for security applications.

핵심 키워드: anon.li, AES-256, HTTP fragment, RFC 3986
